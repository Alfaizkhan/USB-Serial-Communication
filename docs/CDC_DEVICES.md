# USB CDC-ACM Device Support

Native USB devices implement the USB CDC class without dedicated bridge ICs:
- **Arduino**: Uno R4, Leonardo, Micro, Due, Mega (via 16U2)
- **Raspberry Pi**: RP2040 / RP2350 (Pico, Pico W)
- **Espressif**: ESP32-S2, ESP32-S3, ESP32-C3, ESP32-C6
- **STMicroelectronics**: STM32F103 (Blue Pill), STM32F4 Nucleo
