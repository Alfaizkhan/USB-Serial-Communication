# Communications Glossary

- **Baud Rate**: Modulation rate in symbols per second (equivalent to bps in binary NRZ).
- **CDC-ACM**: Communications Device Class - Abstract Control Model.
- **CTS**: Clear to Send. Hardware input signal.
- **DTR**: Data Terminal Ready. Hardware output signal.
- **RTS**: Request to Send. Hardware output signal.
- **UART**: Universal Asynchronous Receiver-Transmitter.
