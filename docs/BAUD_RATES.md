# Supported Baud Rates

## Standard Rates
- 300, 600, 1200, 2400, 4800, 9600
- 19200 (Default application baud rate)
- 38400, 57600, 115200, 230400, 460800, 921600

|---|---|---|
| FTDI FT232R | 300 | 3,000,000 |
| Silabs CP2102 | 300 | 1,000,000 |
| Prolific PL2303 | 75 | 6,000,000 |
| WCH CH340G | 50 | 2,000,000 |
