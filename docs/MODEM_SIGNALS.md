# Modem Control Signals

- **CD (Carrier Detect)**: Remote data link carrier signal.
- **CTS (Clear to Send)**: Transmitter flow clearance.
- **DSR (Data Set Ready)**: Modem operational status.
- **DTR (Data Terminal Ready)**: Terminal session initialization.
- **RTS (Request to Send)**: Receiver readiness.
- **RI (Ring Indicator)**: Incoming line signal.
